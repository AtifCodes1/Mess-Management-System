#  Mess Management System

A web-based **Mess Management System** developed for **Namal University** to digitize and streamline mess operations.

##  Project Summary

The Mess Management System is a user-friendly website designed to replace manual registers, cash handling, and disorganized queues with a digital platform.

The system aims to make meal ordering and mess administration easier for students, the Finance Department, and the Mess Manager.

## ✨ Key Features

- **Weekly Menu:** Students can view the weekly menu online.
- **Meal Pre-Ordering:** Students can pre-order meals 1–2 hours before break time and reserve a specific pickup time.
- **Digital Order Token:** A digital token is issued after order confirmation, displaying the selected items, order price, and assigned pickup time.
- **Student Digital Accounts:** Students can deposit funds into their accounts.
- **Automated Meal Charges:** Meal charges are automatically deducted from student accounts.
- **Real-Time Balance Tracking:** Students can track their account balance.
- **Administrative Monitoring:** The Finance Department and Mess Manager can track student account balances, monitor transactions, oversee daily revenue, and manage mess fee clearances.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **Database:** MySQL
- **UI/UX Design:** Figma
- **Documentation:** Microsoft Word
